# ReadRelay

ReadRelay syncs read status for selected Gmail messages forwarded between two mailboxes.

## Language

**Primary mailbox**

The Gmail mailbox where the user receives and reads the original message.

**Secondary mailbox**

The Gmail mailbox that receives forwarded copies and supplies messages for Dot’s digest.

**Original message**

A message received in the primary mailbox.

**Forwarded copy**

The message delivered to the secondary mailbox by forwarding an original message.
